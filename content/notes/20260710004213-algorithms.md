## Sorting {#sorting}


### Orasort {#orasort}

Compares CPU registers of each string (8 bytes on x64), converts them to 64-bit integer, and compares them. The usual way is to compare letter by letter. By comparing by register, there are less comparisons and the CPU fetch is still fast.
