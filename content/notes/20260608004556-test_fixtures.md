This is just something (like a suite or device) which tests software or electronics. For electronics this is generally a device which holds the chip or board in place and sends it controlled signals. Examples are bed of nails tester (?) or smart fixutres (?). From research, it seems like

-   In-Circuit Test Fixtures (ICT) test every component on the board usually via either bed of nails tester or a flying probe (?)
-   Function Test Fixture (FCT) does a emulation or stimulation of the production environment on the board to ensure it works correctly, this is usually done via test software

Much of these are for large manufacturing plants. On the software side, the test fixture generally just sets up system input state. there are three main types of fixtures.

in-line
: test fixture is created in the same method as the test, generally leads to duplication

delegate
: test fixture is placed in stand alone method which is then used by several test methods

implicit
: test fixture is placed in a setup method which is then used to create multiple other test methods, this is like delegate but instead handles multiple methods

The preparation of **mock objects** are such examples of test fixtures. A **test harness** sets up test fixtures. Mocking can also be seen as usage of a **test double**, that is, some interface which is a simplified version of what is seen in production.

For example, instead of a database, you can mock a fake database. Or instead of using an actual sensor, you can mock one.
