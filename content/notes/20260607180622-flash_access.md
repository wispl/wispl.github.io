Both Nor and Nand flash utilizes erase blocks. But Nand flash employs pages to alleviate its poor read performance.

1.  Nor flash uses a large data bus to allow read and write access to any byte
2.  Nand flash uses a page index and a column index to write to any byte

In particular, most Nand flash require you to send some kind of Write Enable signal before writes. They may also require you to Unlock the chip for writing first. The page read feature makes Nand faster at sequential reads, but only for large read sizes. Hence it is a good idea to try to saturate the page when possible. Some Nor flash might also allow you to do buffer programming, which is similar to page writes emulate page programming for Nor, as an optimization for slow writes.

For both cases, cells must be erased before data can be written to. Recall this is the Program Erase cycle. Nor flash has a sower erase but while Nand flash has faster erases, its block size is larger.
