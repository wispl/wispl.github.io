This is from "Herb Sutter's favorite C ++ 10-liner" for a thread-safe cache.

This utilizes `shared_ptr` to keep an object in memory as long as there is a reference. Once there reference count is zero, the object is unloaded. This may not be the cache you are looking for, or it might be.

```c++
struct Data {
  std::string id;
  std::string name;

  Data(const int id_, const std::string& str_) : id(id_), str(str_);
};

// Generally going to be a singleton
class DataCache {
private:
  static std::mutex mutex;
  static std::unordered_map<std::string, std::weak_ptr<Data>> cache;

public:
  std::shared_ptr<Data> get(const std::string& name)
```
