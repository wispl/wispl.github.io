## Introduction {#introduction}

Sometimes I have to use MongoDB. This is different from SQL databases like MariaDB or PostgreSql. In particular Mongo is rather convenient with Node.js because the documents are essentially JSON, which explains why it is soooo popular in web development. Mongo is also generally easier to set up than PostgreSQL (though you can also use MariaDB if your application isn't too big).


## Differences {#differences}

Mongo is a document database, which stores data (key-value pairs) in JSON documents. The documents are really flexible and you can store a wide variety of data types, including arrays. The document is then organized into collections. The documents can also be dynamic. Just think of a collection as a JSON array, with each JSON document being a data point.

This is different from SQL databases. SQL databases are RDBMS which means they are relational, while ORDBMS (PostregreSQL) means there is object oriented features on top of relations. These databases are more familiar, storing data as a row with an index and its properties. Each row is a data point and each column indicates the property.

SQL databases define relationships using foreign keys, while in Mongo, you use denormalization which just means embeding related data within documents. The reason for denormalization is Mongo is really bad at **joins**, so you want to minimize it. This is different from SQL databases which primarily uses joins with foreign keys to group data.

Also Mongo kind of discourages **transactions**, since there are generally more ways to avoid them.
