Other languages typically handle polymorphic types for you, using syntax sugar of some kind. Of course, C is very bitter, so you don't have sugar of any kind, except for the pointy ones. Therefore you have to make your own.

-   [Tagged Unions](@/notes/20260710145041-tagged_unions.md)
-   [Vtables](@/notes/20260710160734-vtables.md)

Of course, C++ doesn't have this problem since it has classes. But there is a performance hit in some cases.
